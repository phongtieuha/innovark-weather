# Innovark Weather components

Stories for `@innovark-weather/components` (`src/Innovark.Weather.UI/Innovark.Weather.Components`), the component
library behind the web app (`src/Innovark.Weather.UI/Innovark.Weather.Web`).

- **Application**: form building blocks. `ControlledField` for react-hook-form fields with
  collapsing errors, `fetchApiAsync` (the fetch function for Orval's generated hooks) and
  `toProblemState` for requests that return ASP.NET ProblemDetails, and `useFormAction` for the
  result alert.
- **Display**, **Forms**, **Interaction**: shadcn/ui components with the default theme.

API calls are answered by [MSW](https://mswjs.io) (`src/mocks/handlers.ts`), which mocks the web
app's `POST /api/weather/history`. Each story picks one outcome: success, validation error, server
error or network error.

Every story is also a test (`bun run test`): it must render, pass its play function, and pass the
WCAG 2 A/AA checks of the accessibility addon.
